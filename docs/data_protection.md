# 数据保护与规则版本复核

入口：知识系统 → 数据保护。此功能不生成视频、不上传数据，也不推送 GitHub。

## 备份、校验和恢复演练

- 默认包含受管理的 `output/`、`cache/`、`state/` 内分析证据、知识成果、复核记录、抓取进度、任务数据库和工具内制作素材。未知文件保守保留。
- 下载视频/音频（包括 `.mp4.part`）与模型默认不备份，可勾选包含。制作目录内的音视频默认包含。
- 配置在默认目录外的制作目录、任务/进度/分析数据库纳入清单。登录会话、Cookie、环境配置、密钥、链接目录、既有隔离区和演练目录排除。
- 外部 CapCut 草稿及工程引用的任意外部素材、程序代码、Python 环境不在此数据快照范围。不能把这个快照当作整机备份。
- 备份先写 `backups/<编号>.partial`，完成文件数量、大小和 SHA-256 校验后才发布。失败/取消的片段不会出现在可用备份列表里。
- SQLite 使用在线备份，并将目标转为独立文件；DuckDB 通过内部数据库复制保存结构与数据，避免 Windows 文件锁问题。两者各自一致，不宣称多个数据库处于同一瞬间的全局事务快照。
- 已有 JSON 解析错误会原样保存，并单独列为格式警告；校验通过只证明复制完整，不代表有问题的原始内容已修复。
- 恢复演练写入 `restores/<备份编号>-<随机编号>`，校验恢复文件，不覆盖现用数据。`restore_report.json` 提供路径映射。尚未提供一键切换现用数据；跨机器迁移仍需重绑定工程/数据库内的绝对路径。
- 本机同盘备份能防误删，但不能防硬盘损坏。重要快照应另行复制到外置盘并重新校验。

Web 任务和主 CLI 使用共享数据锁；备份、演练和隔离使用独占锁。等待期间可取消，60 秒未获得锁则失败并提示重试。外部程序或未接入锁的维护脚本不受此锁约束，执行数据保护时应停止它们。复制/校验按文件与数据块检查取消；数据库内部复制可能需等当前数据库操作返回，不保证瞬时取消。

命令行（项目根目录）：

```powershell
python tools/manage_data.py inventory
python tools/manage_data.py backup
python tools/manage_data.py list
python tools/manage_data.py verify --snapshot <编号>
python tools/manage_data.py restore-drill --snapshot <编号>
```

## 安全清理的当前边界

本次只允许隔离两个可重建索引：

- `cache/knowledge_base/index.json`
- `cache/creator_knowledge_base/rule_index.json`

必须先选择已经校验的备份，确认现用文件与备份哈希相同，且重建来源仍存在，再生成预览令牌。执行时重算清单，拒绝过期预览。

隔离位置：`state/quarantine/<编号>/files/`，操作日志为同目录 `manifest.json`。撤销验证哈希并拒绝覆盖已存在的文件。中途退出的移动通过日志与实际文件共同核对后恢复。

隔离是移动，不是永久删除，释放磁盘空间为 **0**。不提供自动删除研究视频、证据、规则、复核或进度数据库的功能；请勿把“索引清理”理解为可以删除整个 cache/output。

## 规则复核绑定版本

- 内容指纹覆盖定义、条件、目标、动作、约束、选择方式等；语义变化时 `content_revision` 增加。生成时间变化不改变内容版本。
- 决定保存内容指纹、版本和证据绑定；规则定义变化、已审证据移除、证据类型变化、反例记录变化，均转为 `under_review`。只增加来源 ID 不自动废弃旧决定。
- 证据绑定 v2 同时保存观察内容和代表样例的指纹；同一编号下的信号、时间位置、来源或解释变化也会令旧复核失效。观察绑定覆盖所有被引用观察，不只前几个展示样例；读取库时从实际 `observation_library` 重新计算，不盲信缓存哈希。
- 不因播放量或相对播放指数的单独变化废弃结构复核。新增证据若导致展示样例轮换/旧样例消失，仍会保守要求重新确认。旧的仅编号绑定需重新复核。
- 旧决定未绑定版本时保留历史，但必须重新确认，不能继续充当新规则的批准。
- 界面提交携带内容/证据令牌；页面打开后规则已变化时，拒绝提交并提示刷新。
- `rule_reviews.json` 保存追加的复核历史及当时完整规则快照；`rules/versions/<内容指纹>.json` 保留不同语义版本。重建和复核共用文件锁，避免同时覆盖。
- 保存决定不会立即重建知识系统；点击“完整更新”才会应用到生成产物。规划器也检查已应用复核是否过期。

这不是自动验证创作效果。状态为 `validated` 仍不意味着已经证明留存率等因果效果。
